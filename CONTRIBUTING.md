# Contributing to CutX

Thank you for your interest in contributing to **CutX**! We welcome bug reports, feature suggestions, documentation improvements, and code contributions.

---

## 🧭 Code of Conduct
Please be respectful, constructive, and considerate when interacting with the community.

---

## 🛠️ Development Setup

### Prerequisites
* macOS 13 (Ventura) or later
* Xcode 15+ / Swift 6.0+
* Git

### Steps
1. Fork and clone the repository:
   ```bash
   git clone https://github.com/YOUR-USERNAME/cutX.git
   cd cutX
   ```
2. Build the project:
   ```bash
   swift build
   ```
3. Test locally:
   ```bash
   swift run
   ```

---

## 📦 Submitting Changes

1. Create a descriptive branch:
   ```bash
   git checkout -b fix/sound-feedback-delay
   # or
   git checkout -b feat/drag-and-drop-support
   ```
2. Ensure your code follows the existing style and adheres to the guidelines in [docs/ARCHITECTURE_BLUEPRINT.md](docs/ARCHITECTURE_BLUEPRINT.md).
3. Commit with clear, concise messages.
4. Push and submit a Pull Request against the `main` branch.

Thank you for helping make CutX better for everyone!
